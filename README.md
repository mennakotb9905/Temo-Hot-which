# 🍔 مطعم Temo (Hot Which) - الموقع الرسمي والمنيو الإلكتروني التفاعلي

موقع ويب وتطبيق ويب تقدمي (PWA) لمطعم **Temo (Hot Which)**، مصمم ومطور بأعلى معايير التصميم العصري والـ Glassmorphism مع ميزات تفاعلية متقدمة ومساعد ذكي مدمج.

---

## 🌟 الميزات الرئيسية

- 📱 **تطبيق ويب تقدمي (PWA & Offline First)**:
  - إمكانية تثبيت المنيو مباشرة على الشاشة الرئيسية للهواتف الذكية (Add to Home Screen).
  - دعم العمل بدون إنترنت (Offline) عبر Service Worker مخصص لكاش الملفات.
- 🤖 **شيف تيمو الذكي (AI Assistant)**:
  - مساعد ذكي ومستشار طعام تفاعلي (NLP محلي فوري 0ms) لمساعدة العملاء في اختيار الوجبات حسب الميزانية أو عدد الأفراد.
  - إجابة دقيقة لأسعار كافة الأصناف الـ 87 صنفاً عبر 14 قسماً بالكامل.
  - اقتراح الوجبات الأكثر طلباً والأكلات السبايسي وأزرار للطلب الفوري عبر الواتساب.
- ☁️ **مزامنة التقييمات السحابية (Real-Time Cloud Reviews)**:
  - تكامل متكامل مع Google Firebase Firestore لنشر وقراءة تقييمات العملاء في الوقت الفعلي مع نظام Fallback محلي آمن.
- 🔍 **محرك بحث وتصفية فوري (Instant Menu Search)**:
  - بحث لحظي وسلس عن أي وجبة أو ساندوتش في المنيو.
- ⚡ **أزرار تواصل وإجراءات سريعة (Floating Quick Actions)**:
  - زر اتصال هاتفي مباشر (	el:01034645003).
  - مراسلة فورية عبر واتساب لطلب الأوردر مع نص مهيأ.
  - موقع الفرع الدقيق على Google Maps (طوخ طنبشا - ريست مول أمام الجامعة الأهلية).
  - زر مشاركة رابط المنيو لأي جهة اتصال على الواتساب.
- 🎨 **تصميم زجاجي فاخر (Modern Luxury Glassmorphism)**:
  - خلفيات ضبابية متعددة الطبقات وإضاءات نارية ناعمة وتأثيرات جزيئات نار متطايرة (Floating Embers).
  - تجاوب كامل مع كافة مقاسات الشاشات (الهواتف، التابلت، الشاشات العريضة).

## 📁 هيكلية المشروع

`
Hot Which temo/
├── index.html        # الهيكل الدلالي للموقع
├── style.css         # ملف التنسيقات وتصميم الـ Glassmorphism والتجاوب
├── script.js         # المنطق البرمجي، بيانات المنيو، الذكاء الاصطناعي، وفايربيس
├── manifest.json     # ملف تعريف الـ PWA لتثبيت التطبيق
├── sw.js             # Service Worker لتخزين الكاش والعمل بدون إنترنت
├── favicon.ico       # أيقونة المتصفح
└── assets/           # الشعار والأيقونات بدقة عالية
`
